# Godhury Marketing Communication

Official web platform for **Godhury Marketing Communication**, a Bangladesh-based advertising and marketing communications company.

🌐 **Live Website:** https://www.godhurymarketing.com

## Overview

This project was built as a modern responsive company website showcasing Godhury Marketing Communication's services, portfolio, experience, and client work.

## Project Status

Active and maintained. The public repository contains a sanitized version of the live Godhury Marketing Communication website and is used to showcase the project's structure, features, and technology stack.

## Features

- Responsive multi-page website
- Services and portfolio sections
- Interactive animations and visual effects
- 3D billboard experience
- Client showcase
- Contact and quotation request system
- Supabase-powered form submissions
- Vercel deployment and security headers

## Technologies

`HTML` · `CSS` · `JavaScript` · `Supabase` · `Three.js` · `Git` · `GitHub` · `Vercel`

## Deployment

The website is deployed on **Vercel**, with **Supabase** handling form submissions and backend data. Production credentials and internal-only configuration are excluded from this public repository.

## Security

This is a sanitized public version of the project.

Administrative interfaces, internal reports, production-only files, and private credentials are intentionally excluded. Database access is protected using Supabase Row Level Security policies.
