## Project Overview

This repository contains the **sanitized public version** of the official Godhury Marketing Communication website.

The project combines a multi-page company website with interactive motion, portfolio presentation, responsive layouts, and a custom 3D billboard experience. It was built as part of Godhury Marketing Communication's digital infrastructure and is actively maintained.

## Highlights

- Responsive multi-page company website
- Dedicated services and portfolio experiences
- Interactive animations and scroll-based visual effects
- Custom **Three.js 3D billboard** experience
- GSAP-powered motion and scroll interactions
- Client and project showcase sections
- Contact and quotation request experience
- Supabase-backed form and backend workflows
- Production deployment on Vercel
- Security-focused public repository with private production resources excluded

## Interactive Experience

One of the project's distinctive elements is a custom 3D billboard sequence built with **Three.js** and animated with **GSAP ScrollTrigger**. The experience loads a GLTF billboard model, applies Godhury branding, responds to scrolling, and uses viewport-aware rendering for better performance.

## Deployment & Security

The production website is deployed on **Vercel**, with **Supabase** supporting backend data and form workflows.

This public repository is intentionally sanitized. Administrative interfaces, internal reports, production-only files, private credentials, and other sensitive configuration are excluded. Database access is protected using Supabase Row Level Security policies.
